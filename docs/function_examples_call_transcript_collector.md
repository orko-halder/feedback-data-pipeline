## 7. `pack_turns`

Pack whole turns into chunks of <= max_bytes. Splits only BETWEEN turns; a single turn over the limit is the only thing ever cut, and it is flagged.

```python
>>> pack_turns(["Hello.", "How can I help?"], 100)
[{'text': 'Hello. How can I help?', 'n_turns': 2, 'truncated': False}]
```

```python
>>> pack_turns(["a" * 30, "b" * 30], 40)
[{'text': 'aaaaaaaaaaaaaaaaaaaaaaaaaaaaaa', 'n_turns': 1, 'truncated': False},
 {'text': 'bbbbbbbbbbbbbbbbbbbbbbbbbbbbbb', 'n_turns': 1, 'truncated': False}]
```

```python
>>> pack_turns(["short", "x" * 50, "after"], 40)
[{'text': 'short', 'n_turns': 1, 'truncated': False},
 {'text': 'xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx',
  'n_turns': 1,
  'truncated': True},
 {'text': 'after', 'n_turns': 1, 'truncated': False}]
```
